12-10，GA

Devin is generally available, with backlist/demo products entering paid availability at launch in March.

public node · It is necessary to separate "March sensation" from "December openness" to clarify the commercialization cycle. GA still does not mean that all tasks are completed reliably.

12-11, Experimental Model and Experimental Agent

Gemini 2.0 Flash Experimental was released; Google also disclosed Jules, integrating GitHub issues, planning and execution, and accepting developer supervision.

public node · Model native tool usage is integrated with task-based code agents. Jules is experimental and not fully publicly available at this time; Flash's image/audio output is also only available early access to some partners.

Original source 1

12-17 & 12-18, Product/Distribution

The Agent of Cursor 0.44 can read exit codes/lint, run commands in the background, and has Yolo Mode to automatically run commands; the next day Copilot Free launched with 2,000 completions and 50 chats per month.

public node · Two different directions: the degree of execution autonomy is deepened; the access threshold for developers is lowered. Yolo's ability to automate execution does not mean that all tasks should be delegated by default; the free quota is only a rule released at that time.

12-17, API layered openness

o1-2024-12-17 API adds function calling, Structured Outputs, developer messages, vision and reasoning_effort, rolling out to usage tier 5 first.

public node · The inference model from September to December can be more completely connected to tool-based applications, which is a substantial stage change; the launch of ChatGPT's o1 is an earlier independent time point.

12-26, model/API release

DeepSeek-V3 releases and upgrades deepseek-chat, emphasizing strong code/universal performance and inference economy; the technical report is subsequently made public.

public node · Pave the way for the open model and Agent cost competition in 2025; do not write R1, Changsi, or later Agent capabilities into the V3 release in advance.
