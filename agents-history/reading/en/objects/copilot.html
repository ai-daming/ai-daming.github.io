Direct event

02-27，GA

GitHub Copilot Enterprise is generally available for: org code/knowledge, GitHub.com chat, and more, with a launch price of $39/user/month.

2024-12

Direct event

12-17 & 12-18, Product/Distribution

The Agent of Cursor 0.44 can read exit codes/lint, run commands in the background, and has Yolo Mode to automatically run commands; the next day Copilot Free launched with 2,000 completions and 50 chats per month.

public node · Two different directions: the degree of execution autonomy is deepened; the access threshold for developers is lowered. Yolo's ability to automate execution does not mean that all tasks should be delegated by default; the free quota is only a rule released at that time.

Original source 1 Original source 2

Human–agent collaboration that month (industry-wide)

People learn version recovery, requirement description, deployment and delivery

Execute coding tasks more continuously and autonomously; the direction of a general Agent model is emerging, and non-coding examples are to be filled.
