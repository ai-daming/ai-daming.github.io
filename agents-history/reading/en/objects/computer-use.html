Human–agent collaboration that month (industry-wide)

People are beginning to coordinate multiple agents, yet practice reports still require humans to check annual-report page numbers, correct row references and detect business-level API failures behind successful HTTP responses. Some delegate judgment while others strengthen acceptance checks; a causal link from attention demands to surrendered judgment remains unproven.

Multi-agent division of work and continuously running harnesses are entering practice, alongside reports of idle loops, false passes and failed verification. L1 observes, L2 advises, L3 requires approval for each execution, and L4 executes autonomously, classified per action. Permissions, budgets, stopping rules and independent checks jointly define the boundary.
