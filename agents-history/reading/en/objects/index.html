Object directory · Coding Agent History

A month-by-month history of coding agents, models, engineering methods and autonomous work, from January 2024 through September 21, 2026.

Cursor

Products/Tools · Cursor Team

A product line ranging from code editor interaction and multi-file modification to background tasks and multi-agent working methods. Composer models are archived separately.

GitHub Copilot

Products/Tools · GitHub

Product lines including completion, Chat, Enterprise, IDE agent mode, asynchronous coding agent and CLI; each entry status is recorded separately.

Claude Code

Products/Tools · Anthropic

A software task agent that starts in the terminal and extends to IDE and web page delegation. Separate from the Claude model family.

Codex

Products/Tools · OpenAI

CLI, cloud, IDE and desktop workbench product lines starting in 2025; do not consider 2021 namesake models as cost products.

Devin

Products/Tools · Cognition

An agent product that uses software task delegation as its entrance; demonstration, candidate, and general availability are separated.

Replit Agent

LiveCodeBench

OSWorld

autoresearch
