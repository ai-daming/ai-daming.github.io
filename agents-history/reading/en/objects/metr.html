2025-03

Direct event

03-19

METR proposes to measure the Agent's ability by the time it takes humans to complete it. The original study pointed out that a 50% success rate corresponds to a doubling of task time approximately every 7 months. This indicator expands "how many questions are answered correctly" to "how long the task can be independently undertaken"; it is not a guarantee of the autonomy time for actual projects.

2025-07

Direct event

07-04；07-10

Two corrections for business and productivity: Cursor apologized for billing communications and promised to refund unexpected expenses; METR RCT found that using early 2025 AI tools increased 19% in 246 real tasks among 16 senior open source developers. The main tool is Cursor Pro + Sonnet 3.5/3.7, which cannot be promoted to all developers, all tasks or the end-of-year model.

2026-02

Direct event

02-24 (published)

METR announced modifications to the developer productivity experiment: developers/tasks who are unwilling to work with AI disabled are more likely to exit the sample, and multiple agents working at the same time also destroy the per-task timing.

public node · This is a change in the evaluation system. Follow-up experiments with selection bias cannot be used to introduce a proven unified speed-up ratio, let alone the results of 2025 can be used unchanged in 2026.

2026-05

Direct event

05-11 (published; surveyed 02-04 months)

METR released a self-reported survey of 349 technical workers, which separated the "value increment" and "speed increment" of work.

public node · Users' self-reported median value change is about 1.4-2 times, and the speed is about 3 times; this is a self-reported result, not a random experimental verification. Producing more low-value products may make the speed look better but the value will not increase.
