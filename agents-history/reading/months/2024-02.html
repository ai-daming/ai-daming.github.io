2024-02 · Coding Agent 月度演化史

资料截至 2026-09-10；2026 年 9 月尚未结束。

产品与功能

Cursor Interpreter 更新；Copilot Enterprise GA

模型进展

Gemini 1.5 Pro 长上下文私测；StarCoder2

任务与协作

局部代码问答扩至较大代码上下文与组织知识

工程方法

实验性工具使用；保存时 AI 检查；企业知识接入

评测证据

Gemini 长代码示例为厂商演示；独立落地效果待补

产业与成本

Copilot Enterprise 发布价 $39/人/月；StarCoder2 开放模型与训练资源

群聊与实践

付费、需求表达和代码质量一起被讨论；企业版主要是发布资讯。

人本位

人提交更多材料、询问组织代码，判断答案及付费价值

Agent 本位

实验性使用工具、检查代码；企业问答不等于自主完成办公流程

原文与资料

原底稿 4 条公开记录；新增 7 条官方更新索引；1 项原文

待补与待核

企业真实采用与非编码案例待补；长上下文不保证可靠理解

02-15，实验功能更新

Cursor 0.27 更新 Interpreter Mode 的工具使用与项目理解，并增加保存时运行的 AI linter。

公开节点 · 不能把 2024 上半年的 Cursor 仅描述为 Tab 补全：其产品已在探索执行工具及主动检查。该版本仍称实验功能。

02-15，有限私测

Gemini 1.5 Pro 发布，有限开发者/企业客户可试 100 万 token 上下文；公告示例包括 3 万余行代码。

公开节点 · “把更大代码库交给模型”成为模型路线；上下文长度不是可靠理解/修改整库的证明。

02-27，GA

GitHub Copilot Enterprise 一般可用：组织代码/知识问答、GitHub.com chat 等，发布价 39 美元/用户/月。

公开节点 · 商业价值从“帮我写函数”扩到理解组织代码和流程；这是企业助手，不是后台独立领 issue 的 coding agent。

02-28，模型/数据发布

公开节点 · 开放代码模型路线为可部署、可研究的编程工具提供底座；不能称其本身已是 Agent。
