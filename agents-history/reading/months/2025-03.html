2025-03 · Coding Agent 月度演化史

资料截至 2026-09-21；2026 年 9 月尚未结束。

产品与功能

Manus 推出；Responses API/Agents SDK

模型进展

Gemini 2.5 Pro Experimental；DeepSeek-V3 更新

任务与协作

通用云端任务与编码并行；需求讨论转为设计材料

工程方法

tracing；Groundhog/specs；工具与任务状态

评测证据

METR 按人类任务时长衡量能力；群内修改及课程反馈

产业与成本

TRAE 免费与访问便利推动试用；Manus 邀请机制

群聊与实践

需求讨论难以保存为设计文件，Cursor 乱改影响课程体验；免费、访问便利影响试用。

人本位

人整理目标、保存设计，判断工具是否适合工作

Agent 本位

通用 Agent 自主规划多工具任务；编码与资料处理并行，成果仍需核验

原文与资料

原底稿 6 条公开记录；新增 54 条官方更新索引；2 项原文

待补与待核

Manus 时区与首发日待固定；实验模型非 GA；课程退款公告非到账证明

完整月内事件

03-01

Geoffrey Huntley 展示 Claude Code 对官方 npm 包的 cleanroom transpilation。Agent 产品内部编排开始成为开发者研究对象；不能将它写成官方开源或等价于原始 source-map 泄露。

公开节点 · 状态及限制见来源原文。

03-03

Huntley 的 Groundhog/specs 文章，讨论设计文档、类型/编译错误与生成循环的结合。说明后来的 spec-driven 趋势有此前社区实践。

公开节点 · 状态及限制见来源原文。

原始来源 1

03-11

OpenAI 发布 Responses API、内置 web/file/computer-use 工具、Agents SDK 和 tracing；Agent 的基础工具循环与可观察性被平台化，属于开发基础设施而非 Codex 产品发布。

公开节点 · 状态及限制见来源原文。

原始来源 1

03-19

METR 提出按人类完成时长衡量 Agent 能力，原研究指出 50% 成功率对应任务时长约每 7 个月翻倍。这个指标把“题做对多少”扩展为“能独立承担多长任务”；不是现实项目自治时长保证。
