对象目录 · Coding Agent 演化史

以月为单位梳理 Coding Agent、模型、工程方法及自主工作的演化。资料覆盖 2024 年 1 月至 2026 年 9 月 10 日。

Cursor

产品 / 工具 · Cursor 团队

从代码编辑器交互、多文件修改到后台任务和多 Agent 工作方式的产品线。Composer 模型单独建档。

GitHub Copilot

产品 / 工具 · GitHub

包含补全、Chat、Enterprise、IDE agent mode、异步 coding agent 和 CLI 的产品线；各入口状态分别记录。

Claude Code

产品 / 工具 · Anthropic

终端起步、扩展到 IDE 与网页委托的软件任务代理。与 Claude 模型家族分开。

Codex

产品 / 工具 · OpenAI

2025 年起的 CLI、云端、IDE 和桌面工作台产品线；不把 2021 年同名模型当成本产品。

Devin

产品 / 工具 · Cognition

以软件任务委托为入口的代理产品；演示、候补与一般可用分开。

OpenHands

产品 / 工具 · OpenHands / All Hands 团队

开源软件任务代理项目，历史名称包括 OpenDevin；本次资料未固定最初提交日期。

Cline

产品 / 工具 · Cline 项目团队

早期名为 Claude Dev 的开源编码助手，现有记录覆盖初期展示及 Plan/Act 方法。

Windsurf

产品 / 工具 · Windsurf 团队

以 Cascade 串联代码库上下文和工具执行的编辑器。收购签约与完成交割不混记。

Replit Agent

产品 / 工具 · Replit

在应用开发环境中根据自然语言配置环境、生成代码和部署的任务入口。

Jules

产品 / 工具 · Google

在云环境中异步修改、测试仓库的编码 Agent，实验、beta 和一般可用分开记录。

Bolt.new

产品 / 工具 · StackBlitz

结合浏览器开发环境生成、运行、修复应用的产品；现有记录以首发演示为主。

Lovable

产品 / 工具 · Lovable 团队

自然语言造应用产品。历史中的 GPT Engineer 品牌不与同名开源项目自动合并。

TRAE

产品 / 工具 · TRAE 团队

AI IDE 及 SOLO 工作方式；全球版与国内版的时间分别记录。

Kiro

产品 / 工具 · Kiro 团队

把规格、hooks、steering 带入开发流程，并扩展 CLI 与自主后台任务的产品。

goose

产品 / 工具 · Block / goose 社区

连接模型与真实工具的开源 Agent；开发和 beta 早于本次资料中的正式推广。

Gemini CLI

产品 / 工具 · Google

Google 的开源终端 Agent；与 Gemini 底层模型分开记录。

Qwen Code

产品 / 工具 · Qwen 团队

Qwen 团队基于 Gemini CLI 改造的编码工具；现有直接记录较少。

Antigravity

产品 / 工具 · Google

以 Agent 管理、浏览器控制和异步开发为入口的产品线，预览状态分别保留。

CodeBuddy

产品 / 工具 · 腾讯 CodeBuddy 团队

编码工具产品线；本次资料已记录 IDE 的 Skills、Plan 和项目指导文件更新，首发仍有缺口。

Amp

产品 / 工具 · Amp 团队

本次收录其项目指导文件向 AGENTS.md 迁移的记录，不能视为完整产品史。

Agent HQ

产品 / 工具 · GitHub

聚合多厂商 Agent 的任务与治理入口；公告中的未来接入不等于当日可用。

ChatGPT canvas

产品 / 工具 · OpenAI

写作和编程的可编辑画布；协作界面不等于后台自主完成整个任务。

Claude Artifacts

产品 / 工具 · Anthropic

在对话旁查看和迭代代码、网页等产物的界面能力；与 Claude Code 分开。

OpenClaw

产品 / 工具 · OpenClaw 项目团队

连接聊天渠道、工具、记忆与重复任务的个人 Agent 项目。更名不是最初创建。

Cowork

产品 / 工具 · Anthropic

将代理执行带到桌面办公的产品；本次首条记录为受限研究预览。

WorkBuddy

产品 / 工具 · 腾讯

桌面工作 Agent，连接企业工作入口；本页先收录已有公开上线节点。

豆包工作

产品 / 工具 · 豆包团队

面向工作产物、工具调用和持续执行的产品，已有资料记录其与飞书企业上下文的连接。

飞书

产品 / 工具 · 飞书团队

本次追踪飞书作为企业上下文与工作平台的关联，不另造一个未经核实的“飞书工作”独立产品。

ChatGPT Work

产品 / 工具 · OpenAI

将 Codex 技术用于跨应用和文件长任务的工作产品；具体套餐开放仍有差别。

Kimi Code

产品 / 工具 · Kimi 团队

Kimi 模型进入编码工作的产品入口；模型发布、工具更新与办公入口分开。

Claude Managed Agents

产品 / 工具 · Anthropic

托管代理 API 产品，本次收录 dreaming、outcomes 和协作更新，不等同 Claude Code 本地功能。

Google Managed Agents

产品 / 工具 · Google

Google 的托管 Agent 入口，本次记录为云端 Linux 沙箱中的公开预览。

Responses API / Agents SDK

产品 / 工具 · OpenAI

Agent 工具调用、执行追踪与开发 SDK 基础设施，不是 Codex 产品首发。

Claude Agent SDK

产品 / 工具 · Anthropic

Claude 代理运行能力的开发 SDK；不与 OpenAI Agents SDK 合并。

GPT / OpenAI 通用模型

模型 · OpenAI

按本次范围追踪通用与推理模型。编码专项 Codex 模型另有页面，模型不自动等于完整 Agent。

Codex 专项模型（2025—）

模型 · OpenAI

2025 年起面向编码任务优化的模型记录，与 Codex 工具分开；2021 年同名模型尚未纳入本范围。

Claude 模型家族

模型 · Anthropic

Claude 模型的能力、接入、访问与费用变化；Claude Code、Artifacts、Cowork 各自建档。

Gemini 模型家族

模型 · Google DeepMind

Gemini 底层模型的长上下文、推理与执行能力记录；CLI、Antigravity、托管产品另有页面。

DeepSeek 模型家族

模型 · DeepSeek

开放代码、推理及通用模型，以及 API 兼容和路由变化；DSH 运行时另行记录。

Qwen 模型家族

模型 · Qwen 团队

通用与代码模型家族的公开节点；Qwen Code 工具单独建档。

Kimi 模型家族

模型 · Kimi 团队

Kimi 模型的编码、多模态、Swarm 与开放进展；服务上线与权重开放日期分开。

GLM 模型家族

模型 · Z.ai / 智谱

GLM 系列的编码、长任务和工具能力；厂商指标与独立评估分开。

MiniMax M 系列

模型 · MiniMax

现有公开节点主要为 M2.5，不能据此补造更早版本或整个系列的首发史。

StarCoder2

模型 · BigCode

开放代码模型及配套训练数据资源；本次直接事件较少。

Composer 模型

模型 · Cursor 团队

Cursor 的自研编码模型记录。早期 Composer 多文件编辑功能归 Cursor 产品页，不与模型混记。

GPT-Rosalind

模型 · OpenAI

面向科学研究工作流的受限模型预览，记录证据整理、假设形成和实验计划能力。

MCP

协议 / 标准 · MCP 项目与 AAIF 生态

模型与工具、上下文接入协议，追踪发布、产品采用和治理变化。

A2A

协议 / 标准 · Google 与协议生态

面向不同 Agent 通信与协作的互操作协议，与 MCP 的职责分开。

AGENTS.md

协议 / 标准 · 开放工具生态 / AAIF

跨工具项目指导文件约定，迁移与治理不是仓库规则文件的发明日。

Agent Skills

协议 / 标准 · Anthropic 发起及开放工具生态

指令、脚本与资料的按需加载封装；产品功能、开放标准和生态采用分别记。

Model Hardware Standard

协议 / 标准 · Anthropic 与研究伙伴

面向实验设备操作的接口标准，本次记录为受限研究预览，非全面开放。

Context Engineering

工程方法 · 工程实践社区

围绕信息、工具、格式及工作状态组织的工程方法；术语传播与更早机制背景分开。

Harness Engineering

工程方法 · 工程实践社区

让模型接上工具、状态、权限与验证的运行和工程方法；没有单一产品的统一出生日期。

Loop Engineering

工程方法 · 工程实践社区

围绕发现工作、分派、执行与验证组织持续循环；命名节点不等于循环机制首次出现。

规格驱动开发

工程方法 · 工程实践社区

把意图、规格、计划、实现和验证联系起来的方法；工具产品化与早期实践并列。

Vibe Coding

工程方法 · Andrej Karpathy / 实践社区

对一种以自然语言和运行反馈推动编程的实践命名，不等价所有 AI 辅助工程。

Ralph

工程方法 · Geoffrey Huntley / 实践社区

通过外层循环、聚焦任务、进度文件与验证推进工作的方法。

Spec Kit

产品 / 工具 · GitHub

规格驱动工作流工具包；建库、首个发行版和宣传介绍日期分别保留。

Computer Use

工程方法 · 多厂商与研究社区

通过观察和操作软件界面完成任务的能力与接口路线，不是单一品牌产品。

AlphaCodium

评测 / 研究 · 论文作者团队

以测试与反复执行修复提升编程题表现的研究流程，结果不外推完整软件工程。

Agentless

评测 / 研究 · 研究项目团队

固定定位与修复流程的研究，评估复杂自治以外的方案。

SWE-agent

产品 / 工具 · SWE-agent 研究团队

针对软件仓库任务的开源 Agent，强调适合模型操作的文件、编辑与测试接口。

AutoCodeRover

产品 / 工具 · AutoCodeRover 研究团队

结合代码结构检索、故障定位与模型生成修复软件问题的工具。

Aider

产品 / 工具 · Aider 项目团队

代码编辑工具，现有资料重点记录编辑格式测试及 Architect/Editor 分工。

SWE-bench Verified

评测 / 研究 · 基准作者与合作方

基于真实软件 Issue 的评测及其 Verified 子集；不同数据集和框架分数不直接互比。

LiveCodeBench

评测 / 研究 · 研究项目团队

持续更新编程题、关注生成、自我修复和执行能力的评测。

OSWorld

评测 / 研究 · 研究项目团队

真实桌面、网页与跨应用任务的执行评测。

METR 研究

评测 / 研究 · METR

任务时长与开发者实际效果研究；随机实验、自报调查及方法更新分开阅读。

AI Scientist

评测 / 研究 · Sakana AI

从研究想法到代码实验、评估和论文生成的研究原型，科学有效性仍需验证。

AlphaEvolve

评测 / 研究 · Google DeepMind

生成、评估、演化筛选候选代码以发现算法的研究系统。

autoresearch

评测 / 研究 · Andrej Karpathy

受约束的自主训练实验循环：修改、运行、测量、保留或丢弃改动。

DeepSeek Harness

产品 / 工具 · DeepSeek

通过插件组合模型、工具、会话、沙箱与循环的 Agent 运行时；不与 DeepSeek 模型合并。

AAIF

组织 / 生态 · Linux Foundation

Agent 互操作项目的中立治理组织，初始贡献包括 MCP、goose 和 AGENTS.md。
