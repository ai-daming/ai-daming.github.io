05-11 (published; surveyed 02-04 months)

METR released a self-reported survey of 349 technical workers, which separated the "value increment" and "speed increment" of work.

public node · Users' self-reported median value change is about 1.4-2 times, and the speed is about 3 times; this is a self-reported result, not a random experimental verification. Producing more low-value products may make the speed look better but the value will not increase.

05-14

OpenClaw switches OpenAI model execution to the Codex app-server by default: Codex is responsible for inner loops such as model rounds, tool continuation, and compression, while OpenClaw retains outer layers such as channels, persona, memory, and cron.

public node · It is a demonstration of "interoperable runtime": universal personal Agents can be combined with Coding Agent Harness, and product relationships cannot be explained only by interface appearance.

public node · The control interface of long-term tasks is separated from the actual execution location; being manageable by a mobile phone does not mean that the mobile phone executes all codes locally.
