All events this month

11-12, complete family release

Qwen2.5-Coder increases 0.5B/3B/14B/32B, forming a six-speed family with the previous two speeds; 32B catches up to GPT-4o in the author's code benchmark.

public node · The open code model gives more complete options for local/different resource scale deployment; "parity" must be limited to the evaluation described, not all engineering tasks.

Original source 1

11-13, publicly available

Codeium releases Windsurf Editor. Cascade combines code base context, tool calls and real-time operations by developers to support continuous multi-file editing.

public node · A key product fork: emphasizing AI sharing progress with people and continuously taking over, rather than one-time chat suggestions or completely offline independent agents. "The world's first Agentic IDE" is what the manufacturer calls itself.

Original source 1 Original source 2

11-24，early agent

Cursor 0.43 adds an early Agent that can select its own context and use the terminal in Composer, and brings inline diff in the sidebar.

public node · Compared with the multi-file generation in July, AI begins to decide on its own what to read and run next; this article is suitable for writing "Cursor Composer Agent".

Original source 1

11-25, open source protocol/SDK

Anthropic releases MCP, Claude Desktop local server support and a batch of reference servers; mentions Zed/Replit/Codeium/Sourcegraph are working together.

public node · Tool/data access has begun to be standardized; it is not that "the entire industry has been unified" that day, and there is still follow-up work on remote production deployment capabilities.
