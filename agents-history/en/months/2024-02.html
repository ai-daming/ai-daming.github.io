Gemini 1.5 Pro is released, limited developers/enterprise customers can try out 1 million token contexts; the announcement examples include more than 30,000 lines of code.

02-27，GA

GitHub Copilot Enterprise is generally available for: org code/knowledge, GitHub.com chat, and more, with a launch price of $39/user/month.

public node · The business value extends from "help me write functions" to understanding organizational code and processes; this is an enterprise assistant, not a coding agent that independently handles issues in the background.
