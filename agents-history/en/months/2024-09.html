All events this month

09-05，early access/alpha

Replit Agent publishes early access to Core subscribers, showing everything from natural language to environment configuration, dependencies, databases, and deployment.

public node · Different from the IDE assistant, it packages the environment and deployment of "producing runnable applications"; the official is clear about alpha and should not write mature GA.

Original source 1 Original source 2

09-05, model merge

DeepSeek-V2.5 merges and upgrades V2 Chat and Coder V2; the two API model names are still backward compatible.

public node · For Agent, common instructions, code and tools need to work together, rather than all capabilities being strictly divided into a "chat model" and a "code model".

Original source 1

09-12，preview

OpenAI o1-preview/o1-mini is launched, using more reasoning calculations before answering, highlighting tasks such as coding and mathematics.

public node · There is a new route for reasoning capabilities, but the tools/system messages/streaming and other capabilities of the first version of the API are limited, and the later complete Agent stack cannot be directly filled back.

Original source 1

09-19, the first batch of open models

The Qwen2.5 family is released, of which the first batch of Qwen2.5-Coder is 1.5B/7B, and 32B is on the way.

public node · Chinese code models continue to catch up, and the full family in November is another event; don't write 32B as being available on the first day of September.

Original source 1

09-26, experimental function

Aider Architect/Editor uses one model to describe the scheme and another to generate specific edits; the motivation is that o1 can reason about but not always output a reliable edit format.

public node · Very specific human-machine/model collaboration product nodes: understanding problems and accurately implementing modifications are two capabilities, and model combination can alleviate shortcomings. 85% is Aider’s own code editing benchmark.
