2024-04 · Coding Agent 月度演化史

资料截至 2026-09-10；2026 年 9 月尚未结束。

产品与功能

SWE-agent；AutoCodeRover；Copilot Workspace 技术预览

模型进展

CodeQwen1.5；CodeGemma

任务与协作

从 Issue 定位问题、计划、修改与测试；人审方案

工程方法

Agent 操作接口；代码结构检索；可检查的计划

评测证据

软件任务评测；OSWorld 计算机任务评测

产业与成本

开源工程 Agent 与开放代码模型增加；商业采用数据待补

群聊与实践

争论 pipeline 与自主规划的区别；零基础用户卡在执行、环境和反复修复。

人本位

人描述问题、检查计划，处理环境与验收

Agent 本位

自主定位、编辑、测试；非编码计算机任务进入系统评测

原文与资料

待补与待核

完整月内事件

04-08，论文 v1

AutoCodeRover 将 LLM 与按类/方法的结构化代码搜索、AST 和测试故障定位结合来修复 GitHub issue。

公开节点 · 强调软件工程知识和检索结构的重要性；不能把它简化为“又一个 Devin”。

04-11，论文 v1

OSWorld 用真实桌面/网页及跨应用任务、执行式检查评估 computer-use agent。

公开节点 · 为后来会看屏幕、点鼠标的 Agent 提供评估基础。不是专门 coding benchmark，但与代码工具扩到浏览器/桌面的路线直接相邻。

4 月，公开项目；04-15 本地仓库里程碑关闭

SWE-agent 开源项目进入可运行工程工具阶段，4 月里程碑包含本地仓库运行、环境安装与 patch 展示。

公开节点 · 研究不止给一段提示词，而是在设计 Agent 使用文件、shell、反馈的接口。通行的 04-02 首发日需再补作者当日原帖；04-15 是版本里程碑而非首次亮相。

04-16，开放模型

CodeQwen1.5-7B 发布，支持代码编辑、92 种语言与 64K 上下文等。

公开节点 · 国内代码模型不能等到 DeepSeek-R1 才进入叙事；此时已经尝试 repo/context 任务，但官方 SWE-bench 结果仍很低。

原始来源 1

04-29，技术预览

Copilot Workspace 以任务为入口，串联理解问题、形成 specification/plan、修改和检查代码，用户可介入调整。

公开节点 · 大平台也在试“自然语言任务→可检查计划→代码变更”；是技术预览，不是全面 GA。
