2025-06 · Coding Agent 月度演化史

资料截至 2026-09-21；2026 年 9 月尚未结束。

产品与功能

Gemini CLI 开源预览；Codex 扩 Plus/联网；Lovable Agent beta

模型进展

Gemini 2.5 Pro 进入 CLI；多模型按任务阶段组合

任务与协作

跨工具交接；CC 团队材料已有财务等非编码用途

工程方法

Context Engineering；MCP 配置；研究→计划→新会话执行

评测证据

魔方迁移多模型复盘；上下文 PPT；非受控排名

产业与成本

Cursor Pro 计费改变、Ultra、Series C；Gemini CLI 免费入口

群聊与实践

魔方迁移在 Claude、Gemini、o3 间交接；Context 进入本地教学，MCP 卡环境。

人本位

人组织上下文、控制预算、排错并完成验收

Agent 本位

自主调用工具完成工程；资料、财务纯文本等工作有使用材料

原文与资料

原底稿 6 条公开记录；新增 83 条官方更新索引；2 项原文

待补与待核

Lovable 原文未全读；MCP 装好不等于任务完成；计费只记当时

06-03

云端 Codex 扩到 ChatGPT Plus，并允许用户为执行过程启用互联网访问。环境准备/依赖获取的摩擦被降低，同时网络成为单独控制面。
