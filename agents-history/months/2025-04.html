2025-04 · Coding Agent 月度演化史

资料截至 2026-09-10；2026 年 9 月尚未结束。

产品与功能

Codex CLI 开源首发；A2A 发布

模型进展

GPT-4.1；o3/o4-mini；Qwen3

任务与协作

产品→PRD→架构→实现→测试的人机团队流程

工程方法

A2A；本地终端执行；故事/计划/验收分工

评测证据

厂商评测；团队自述；线下业务需求调查反例

产业与成本

终端工具与开放模型竞争；公司采购与个人工具分开

群聊与实践

团队从 PRD 经飞书交给架构/编码/测试；做网站不能代替线下业务调查。

人本位

人负责业务发现、架构、交接，网页原型不能替代需求成立

Agent 本位

自主读写仓库、执行代码；跨 Agent 通信标准提出，非编码交付按任务核对

原文与资料

原底稿 4 条公开记录；新增 95 条官方更新索引；2 项原文

待补与待核

A2A 不等于互操作已普及；Codex CLI 与旧 Codex 模型分开

完整月内事件

04-09

Google 发布 A2A，解决不同 Agent 间通信与任务协作；与 MCP 的工具/上下文接入层不同，是跨系统互操作方向。不可写为已经普遍消除协作问题。

公开节点 · 状态及限制见来源原文。

原始来源 1

04-14

GPT-4.1 家族在 API 发布，重心包括代码、指令遵循、长上下文。说明推理模型之外，适合代码编辑与长库理解的非 o 系模型仍在发展。

公开节点 · 状态及限制见来源原文。

原始来源 1

04-16

o3、o4-mini 与开源 Codex CLI 同日发布。CLI 在本地终端阅读、修改、执行代码；这是 2025 Codex 产品线的 CLI 首发，必须与 2021 Codex 模型、5 月云端 Codex 区分。

公开节点 · 状态及限制见来源原文。

04-29

Qwen3 发布，开放模型家族把思考/非思考模式与 Agent 能力作为方向；这是通用底座，不是 7 月的 Qwen3-Coder。
