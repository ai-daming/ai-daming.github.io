2025-10 · Coding Agent 月度演化史

资料截至 2026-09-21；2026 年 9 月尚未结束。

产品与功能

Codex GA；CC web 预览；Agent HQ；Cursor 2.0

模型进展

Cursor Composer 模型；既有模型按角色分工

任务与协作

终端、网页异步、多 Agent 管理；非程序员用 CC 讨论产品

工程方法

Agent Skills；worktree；浏览器测试；SDK/管理接口

评测证据

厂商内部观察；群友短时体验；无统一效率倍数

产业与成本

团队接入、Slack 集成；套餐与额度影响分工

群聊与实践

非程序员用 CC 讨论产品；熟练者多工具分工，但超过四条线就难跟踪。

人本位

人管理任务，仍有安装门槛；并行过多易失去上下文

Agent 本位

自主按需加载专业方法、并行工作；非编码产品思考与专业任务扩展

原文与资料

原底稿 5 条公开记录；新增 220 条官方更新索引；2 项原文

待补与待核

Agent HQ 各伙伴开放日待分；Skills 标准化在12月；安装门槛保留
