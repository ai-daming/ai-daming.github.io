完整月内事件

05-11（发表；调查 02—04 月）

METR 公布 349 名技术工作者自报调查，将工作「价值增量」和「速度增量」分开。

公开节点 · 用户自报中位价值变化约 1.4—2 倍、速度约 3 倍；这是自报结果，不是随机实验验证。做了更多低价值产物，也可能让速度好看但价值没增长。

05-14

OpenClaw 将 OpenAI 模型执行默认切到 Codex app-server：Codex 负责模型轮次、工具延续、压缩等内层循环，OpenClaw 保留渠道、persona、memory、cron 等外层。

公开节点 · 是「可互用的运行时」实证：通用个人 Agent 可以组合 Coding Agent Harness，不能只按界面外观解释产品关系。

05-14

Codex 接入 ChatGPT 手机 app，用户可以远程查看、转向在笔记本、开发机或远程环境运行的任务。

公开节点 · 长时间任务的控制界面与真正执行位置分离；手机可管理并不等于手机本地执行所有代码。

05-19

Claude Managed Agents 推出 dreaming 研究预览，并开放 outcomes、multiagent orchestration、webhooks。Dreaming 定期整理会话和记忆，可自动更新或审核后更新。

公开节点 · Memory 进入维护生命周期：不仅保存，还要归纳、去重、更新。注意这是 Managed Agents API 的发布，不能直接等同 Claude Code 本地某个泄露功能的正式上线。
