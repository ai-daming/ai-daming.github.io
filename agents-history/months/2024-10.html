2024-10 · Coding Agent 月度演化史

资料截至 2026-09-21；2026 年 9 月尚未结束。

产品与功能

Bolt.new；canvas；Copilot 多模型、Spark/Edits 预览

模型进展

更新版 Claude 3.5 Sonnet；computer use beta

任务与协作

浏览器造应用、画布共写、计算机界面操作

工程方法

WebContainers；局部修改；屏幕—点击—输入循环

评测证据

厂商演示/研究预览；课程收官自述含半成品

产业与成本

Copilot 接多家模型；价格、访问渠道影响切换

群聊与实践

课程收官有人做出脚本，也有人仍是半成品；部署、需求、迭代卡住。

人本位

人自然语言生成应用、共写文章，仍监督部署修改

Agent 本位

自主生成、运行、修复应用；computer use 试验性操作软件；canvas 仍由人引导

原底稿 4 条公开记录；新增 17 条官方更新索引；2 项原文

待补与待核

完整月内事件

10-03，early beta

ChatGPT canvas 为写作和编程提供独立可编辑窗口、局部修改与快捷操作，先给 Plus/Team。

公开节点 · 聊天→共同操作一个产物的 UI 变化；不是后台自主完成仓库任务的 Agent。

10-03，发布/大会演示

StackBlitz 在 ViteConf 展示 Bolt.new：浏览器中的完整开发环境，生成、运行、修复、部署应用。

公开节点 · 模型之外，WebContainers 运行时让用户可以即时看见结果；“无需写一行代码/production-grade”是演示营销范围，不是任意业务应用验收。

10-22，模型更新；computer use public beta

更新 Claude 3.5 Sonnet，并公开通过看屏幕、移动光标、点击和打字的 computer use API beta。

公开节点 · Coding Agent 的工具边界从文件/终端扩到真实 UI。它仍试验性、不稳定；“宣布 Haiku 3.5”不表示首日与 Sonnet 同时全面可用。

10-29，分项预览/发布

GitHub Universe 宣布 Copilot 多模型选择、自然语言造应用的 Spark，以及 Copilot Edits 等开发体验。

公开节点 · 模型供应商与开发平台解绑的信号；Spark/Edits 当时的预览不能写成 2025 年 Copilot Agent mode。不同模型/产品开放时间不完全一致。
