2025-05 · Coding Agent 月度演化史

资料截至 2026-09-10；2026 年 9 月尚未结束。

产品与功能

Codex 云端预览；Copilot coding agent；Jules beta；CC GA；Cursor Background Agent

模型进展

Claude Opus 4/Sonnet 4；codex-1

任务与协作

独立环境异步领任务、产出 PR；原型迁移 IDE 迭代

工程方法

云沙箱；任务隔离；review 反馈；AlphaEvolve 评估循环

评测证据

厂商长任务案例；群内工具比较仍有部署失败

产业与成本

多家集中提供异步委托；订阅和开放条件不同

群聊与实践

Bolt/Firebase 快出原型，Cursor 接续迭代；有人仍卡部署 404、计划过期。

人本位

人派任务、审结果、衔接原型与现有系统

Agent 本位

自主修改、测试、提交变更；AlphaEvolve 生成并评估代码以发现算法

原文与资料

原底稿 6 条公开记录；新增 71 条官方更新索引；2 项原文

待补与待核

Cursor 0.50 日期冲突；长时案例非普遍自治保证；部署未完成要保留

完整月内事件

05-15（版本页）

Cursor 0.50 引入 Background Agent，支持后台并行任务；IDE 产品向异步工作延伸。

公开节点 · 状态及限制见来源原文。

05-16

Codex 云端 research preview：基于 codex-1（为软件工程优化的 o3），每任务独立云 sandbox，可并行修复、写功能、提 PR。人从每步驾驶转为委托任务、审查结果。

公开节点 · 状态及限制见来源原文。

原始来源 1

05-19

GitHub Copilot coding agent 首次发布：分配 issue 后在 GitHub Actions 环境工作，推送 draft PR，让人通过 review 反馈。区别于 2 月在 IDE 同步工作的 agent mode。

公开节点 · 状态及限制见来源原文。

05-20

Jules 进入无需 waitlist 的 public beta，克隆仓库到云环境，异步修改、测试并产出变更。它已在 2024-12 亮相，5 月不是首次公布名称。

05-22

Claude Opus 4/Sonnet 4 发布；Claude Code GA，提供 SDK、IDE 集成，GitHub 支持仍 beta。模型长任务能力与可复用 Agent 运行时同步推进。

月内补充，日期见正文
