完整月内事件

09-05，early access/alpha

Replit Agent 面向 Core 订阅者发布早期访问，展示从自然语言到环境配置、依赖、数据库和部署。

公开节点 · 与 IDE 助手不同，它把“产出可运行应用”的环境和部署打包；官方明确 alpha，不应写成熟 GA。

原始来源 1 原始来源 2

09-05，模型合并

DeepSeek-V2.5 将 V2 Chat 与 Coder V2 合并升级；两个 API 模型名仍向后兼容。

公开节点 · 对 Agent，通用指令、代码与工具需要一起工作，而不是所有能力严格分在一个“聊天模型”和一个“代码模型”。

原始来源 1

09-12，preview

OpenAI o1-preview/o1-mini 推出，在回答前使用更多推理计算，突出代码、数学等任务。

公开节点 · 推理能力有新路线，但首版 API 的工具/系统消息/streaming 等能力受限，不能直接把后来的完整 Agent 栈倒填回来。

原始来源 1

09-19，首批开放模型

Qwen2.5 家族发布，其中 Qwen2.5-Coder 首批为 1.5B/7B，32B 在路上。

公开节点 · 中国代码模型继续追赶，11 月完整家族是另一个事件；不要把 32B 写成 9 月首日可用。

原始来源 1

09-26，实验功能

Aider Architect/Editor 用一个模型描述方案、另一个生成具体编辑；动机是 o1 会推理但不总能输出可靠的编辑格式。

公开节点 · 很具体的人机/模型协作产品节点：理解问题和准确落地修改是两个能力，模型组合可以缓解短板。85% 是 Aider 自己的代码编辑 benchmark。
