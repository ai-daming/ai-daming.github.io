2024-08 · Coding Agent 月度演化史

资料截至 2026-09-10；2026 年 9 月尚未结束。

产品与功能

Composer 对 Pro/Business 默认开启；Projects beta

模型进展

GPT-4o-2024-08-06；Structured Outputs；Claude/DeepSeek 缓存

任务与协作

多文件任务常规化；自主研究出现并行分支

工程方法

结构化输出；共享指令；上下文缓存

评测证据

SWE-bench Verified；AI Scientist 研究原型

产业与成本

重复上下文成本降低；订阅、远程环境及额度进入选型

群聊与实践

Cursor 引发项目、远程环境、文档和 Pro 选择问题；网页聊天丢上下文。

人本位

人更常规委托修改，仍判断代码与科学结果

Agent 本位

AI Scientist 展示自主构想、运行实验、评估及生成论文；受限研究环境

原文与资料

原底稿 5 条公开记录；新增 39 条官方更新索引；2 项原文

待补与待核

缓存页面日期漂移；研究原型不等于可靠自主科学发现

完整月内事件

08-02 与 08-14，缓存功能

DeepSeek 推出磁盘上下文缓存；Anthropic 推出 prompt caching public beta，目标包括多轮工具调用和代码库问答。

公开节点 · 重复读同一代码库不必按完全重复输入付全部代价；改善的是推理成本/延迟，不自动改善模型推理正确性。

08-06，GA

OpenAI Structured Outputs 用受约束输出保证符合指定 JSON Schema，并推出 GPT-4o-2024-08-06。

公开节点 · 缓解 Agent 的工具参数/结构格式不稳定；结构正确不保证事实、业务语义或动作正确。

08-13，基准发布

SWE-bench Verified 由专业开发者筛选出原测试集中的 500 个样本，并改进容器化评测环境。

公开节点 · 编程 Agent 宣传开始围绕更可检验的真实 issue；它不是全新随机企业任务集，原始/Lite/Verified 分数不能直接横比。

原始来源 1

08-13，研究原型（并行分支）

Sakana AI Scientist 展示从想法、编写/运行实验到评估与论文生成的研究流程。

公开节点 · 代码执行闭环延伸到研究任务。不能外推成已能替代科学家或自主发现可靠结论；它与普通联网写研究报告不同。

原始来源 1

08-22，默认开启

Cursor Composer 对 Pro/Business 用户默认开启，并加入共享指令的 Composer Projects beta。

公开节点 · 多文件修改从隐藏实验开关走向常规工作流。与 7 月 beta、11 月 Agent 必须分开讲。
