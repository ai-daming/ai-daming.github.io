2025-02 · Coding Agent 月度演化史

资料截至 2026-09-10；2026 年 9 月尚未结束。

产品与功能

Copilot agent mode；Edits GA；Claude Code 研究预览

模型进展

Claude 3.7 Sonnet；R1/Kimi 用于资料分析的群内实践

任务与协作

终端委托、IDE 内执行；Plan/Act 与 BDD 实践

工程方法

vibe coding 命名；规则驱动测试修复；早期 source-map 披露

评测证据

亲述测试循环仍需提醒；厂商展示；无泄露引发生态的因果证据

产业与成本

Claude Code 初次预览；开放推理模型与商业 CLI 组合

群聊与实践

BDD/TDD、Plan/Act 被实际采用，却仍需要提醒；R1/Kimi 和编码工具按阶段分工。

人本位

人定义场景、提醒执行纪律、排查环境版本

Agent 本位

自主选文件、执行命令、据测试修复；资料研究与编码按阶段组合

原文与资料

原底稿 4 条公开记录；新增 26 条官方更新索引；2 项原文

待补与待核

包日/披露日有差异；接入模型、写规则不等于持续遵循

完整月内事件

02-02

Karpathy 提出 vibe coding，描述以自然语言、运行反馈推动周末项目，甚至不再阅读 diff。它给一种已有实践命名，并非 AI 编程首次出现，也不等价所有负责任的 AI 辅助工程。

02-06

GitHub 推出 VS Code Copilot agent mode，同时 Copilot Edits GA；自动挑选文件、执行/修复的 IDE 内循环进入主流工具。还展示 Project Padawan，但后者不能当作 5 月 coding agent 已正式上线。

02-24

Claude 3.7 Sonnet 与 Claude Code 同时发布；前者混合即时回答/扩展推理，后者是终端 agentic coding 工具，状态为 limited research preview。开发者能委托较完整工程任务。

公开节点 · 状态及限制见来源原文。

原始来源 1

02-24 包；02-27 披露

早期 Claude Code npm 包带 inline source map，开发者得以查看实现；Dave Schumaker 记录更新后 source map 被移除、从编辑器 undo 找回的经历。CLI 的工具与编排实现成为公开讨论材料；不是模型权重泄露，也不能据此声称引发整个 Agent 行业。
