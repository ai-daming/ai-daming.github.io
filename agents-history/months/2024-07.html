完整月内事件

07-01，论文 v1

Agentless 用固定的定位→修复两阶段流程，在作者当时 SWE-bench Lite 实验中取得 27.33%、每问题 0.34 美元。

公开节点 · 重要反例：让模型自由决定每一步，并非所有任务里最佳。必须使用 v1；后来的“三阶段/新分数”不能倒填到 7 月。

07-13，beta；07-23 默认模型调整

Cursor 首次提供 Composer 实验性多文件编辑；随后默认模型调整为 Claude 3.5 Sonnet。

公开节点 · 补全→多文件变更的明确产品阶段；此时不等同 11 月自选上下文、调用终端的 Composer Agent。

原始来源 1

07-15 公司；07-23 论文

All Hands AI 宣布围绕 OpenDevin 建公司；月底平台论文出现（后来标题改为 OpenHands）。

公开节点 · 开源工程 Agent 从临时复刻演示向持续研发、实验环境和可用产品发展。不能把 7 月论文当前的 OpenHands 标题当作当时已经改名。

07-15，作者公开展示，已可安装

Claude Dev（后来的 Cline）作者公开其 Anthropic hackathon 项目，称已开源且在 VS Code Marketplace 可用。

公开节点 · 展示了 VS Code 扩展路线：模型逐步处理任务、用户介入批准。帖子标题写 June hackathon，发帖是 July；项目产生、商店发布和改名不要混在一个日期。

07-18，模型发布；07-25，API 功能

GPT-4o mini 降低多轮调用成本；DeepSeek API 加入 function calling、JSON mode，以及 beta 的 prefix/FIM completion。

公开节点 · “调用得起、工具能接上”也是 Agent 可用性的前提，不能只按最大模型排名选材。
