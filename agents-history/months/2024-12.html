完整月内事件

12-10，GA

Devin 一般可用，3 月发布时的候补/演示产品进入付费可用阶段。

公开节点 · 必须把“3 月轰动”与“12 月开放使用”分开，才能讲清商业化周期。GA 仍不等于所有任务可靠完成。

12-11，实验模型与实验 Agent

Gemini 2.0 Flash Experimental 发布；Google 同时披露 Jules，集成 GitHub issue、计划和执行，接受开发者监督。

公开节点 · 模型原生工具使用与任务型代码 Agent 合流。Jules 是实验，不是此时已经公开全面可用；Flash 的图像/音频输出也仅部分伙伴早期访问。

原始来源 1

12-17 与 12-18，产品/分发

Cursor 0.44 的 Agent 能读退出码/lint、后台跑命令，并有自动运行命令的 Yolo Mode；次日 Copilot Free 推出每月 2,000 补全和 50 chat。

公开节点 · 两条不同方向：执行自主程度加深；开发者接触门槛下降。Yolo 可自动执行不表示应对所有任务默认放权；免费额度仅是当时发布规则。

12-17，API 分层开放

o1-2024-12-17 API 增加 function calling、Structured Outputs、developer messages、视觉和 reasoning_effort，先向 usage tier 5 滚动开放。

公开节点 · 9 月推理模型到 12 月可更完整接入工具型应用是实质阶段变化；ChatGPT 的 o1 首发又是更早的独立时间点。

12-26，模型/API 发布

DeepSeek-V3 发布并升级 deepseek-chat，强调强代码/通用性能与推理经济性；技术报告随后公开。

公开节点 · 为 2025 的开放模型和 Agent 成本竞争铺底；不要把 R1、长思考或之后的 Agent 能力提前写进 V3 首发。
