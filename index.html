02 / METHOD

我不从“AI 能做什么”开始

我从业务现场开始，先确认真正的问题、事实与责任，再决定 Agent 应该获得什么能力。

  1. 01进入现场

    找到真实用户、真实流程和真正承担结果的人。

  2. 02定义事实

    区分“请求已发出”和“客户真的收到并行动”。

  3. 03建立约束

    把身份、权限、恢复和验收变成系统绕不过去的机制。

  4. 04生产验证

    不把 Demo、PR、发布或服务健康冒充业务完成。

03 / PROJECT EXCHANGE

你有一个 AI 项目，
但它还没真正进入生产？

可以告诉我三件事：业务场景、当前卡点、希望我如何参与。
